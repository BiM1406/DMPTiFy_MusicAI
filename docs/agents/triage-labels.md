# Triage Labels

The engineering skills use five canonical triage roles. This repository uses the canonical strings directly.

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Work is waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgment |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a triage role, use the corresponding GitHub label in this table. Do not invent synonymous labels.
